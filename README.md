# 检验项目手册 · 在线浏览版

把《检验项目手册》V3.0.xlsx 变成可在浏览器里搜、可点、可分享的查询页面。
纯静态（HTML + CSS + 原生 JS），无框架、无外部依赖、无后端，离线双击 `index.html` 也能用。

## 能做什么

- **418 个条目全量可查**：158 个组合医嘱 + 260 个单项医嘱，共 1071 条子项明细
- **三个维度筛选**：类型（组合/单项）、医嘱分类（32 类）、责任组室（9 个）
- **多关键词搜索**：项目名、子项名、对应收费、分类、标本、报告时限、组室、修改说明一起搜，空格分隔表示"且"
- **点击查看详情**：组合 → 子项清单（含每项价格、合计）+ 标本/采血管/报告时限/责任组室/电话；单项 → 还被哪些组合包含
- **组合与单项互通**：子项名称可点击跳到对应单项详情，单项详情列出包含它的所有组合（如"葡萄糖(Glu)测定"被 16 个组合引用）
- **可分享的链接**：每条详情都有独立地址（`#/i/p2`），可直接发给同事；"复制链接"按钮一键复制
- 手机、平板自适应；`/` 键快速聚焦搜索，`Esc` 返回列表

## 目录结构

```
index.html            页面骨架
assets/style.css      样式
assets/app.js         渲染与交互逻辑
assets/data.js        数据（由脚本从 Excel 生成，勿手工修改）
tools/extract.py      Excel → data.js 抽取脚本
```

## 数据是怎么来的

`tools/extract.py` 读取同目录上层的《检验项目手册》V3.0.xlsx：

- 表头 A 列「医嘱名称」用合并单元格纵向跨行，一个医嘱占一段行，段内每行是一条子项
- 脚本先展开所有合并单元格，再按 A 列的合并起点切段，得到"医嘱级属性 + 子项清单"
- 子项与单项之间做名称归一化匹配（去空白、统一全半角括号、去"测定/检测"等后缀），
  同名候选不唯一时用**标本类型**消歧（血清/尿液/粪便/拭子…），仍不唯一就放弃链接——
  宁可点不到，也不会让尿液组合里的"肌酐"错误跳到血清肌酐单项
- 当前 811 条组合子项中有 631 条能跳转到对应单项，其余是计算项、不收费项或没有单独开医嘱的项目

### 手册更新后怎么重新生成

```bash
# 1. 覆盖上层的《检验项目手册》V3.0.xlsx
# 2. 重新生成数据
python3 tools/extract.py
# 3. 本地预览
python3 -m http.server 8765     # 然后打开 http://127.0.0.1:8765
# 4. 提交
git add -A && git commit -m "更新手册数据" && git push
```

脚本运行结束会打印一行"数据体检提示"，列出总价与子项合计不一致、标记为组合但只有 1 个子项、
缺分类或组室之类的原始数据问题，方便回头核对 Excel。
